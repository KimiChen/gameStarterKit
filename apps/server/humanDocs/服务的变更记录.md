# 服务的变更记录

> 范围：`server_kxz` 分支自基线 `7b9f831` 至当前提交的能力归纳；按主题记录，不逐条重复提交历史。

## 服务端与基础设施

- 服务端目录重构为 `framework/` 基础框架与 `modules/` 业务模块，玩法、kit、插件与房间仍经既有登记点装配。
- 本地环境统一由根 `.env.development` 驱动；端口、`PROJECT_ID`、Redis/MySQL 命名空间与多项目并行隔离已收紧校验。
- 强化 Redis/MySQL 写路径的锁、fence、幂等、outbox、冷/热档迁移和停服生命周期，并补充真实栈集成测试与故障测试。

## 区服、账号与实时连接

- 区服语义从单账号收紧到 `(账号, 区)`：Lobby、GameRoom、经济、工会、结算和角色档均带区服隔离；撮合与 join 参数增加 `sId` 硬闸。
- 账号/选服改为通过锁定 WebPlatform HTTP 契约消费；本地开发保留 `AUTH_PROVIDER=dev`，可提供开发登录和本地区服目录。
- 完成会话准入、顶号、封禁/强踢、角色 ready、登录回滚与断线重连的边界收口；Lobby RPC 和 GameRoom 均执行共享 wire 运行时校验。

## 契约、玩法与客户端协作

- shared 协议、HTTP/RPC 契约、玩法 state/wire、Schema 与插件/玩法目录生成物进一步收敛到单源及 codegen 流程。
- 完善插件、kit、私房、Snake、Arena、SLG 等样例能力的服务端登记、数据隔离和验证覆盖。
- 客户端保持纯 TypeScript 源码与 Cocos 工程壳分离；同步、第三方运行时锁定、FGUI/UniFlex 产物校验和 ES2017 类型门禁持续加强。

## 验证与当前联调入口

- 增加不依赖 Cocos 的客户端真实服务端联调：客户端 HTTP 封装真实覆盖开发登录、选区、健康、版本、对时和公告；客户端 `WebSocketClient` 真实加入 Lobby，并验证 `user.getUserId`、`user.getInfo` 与主动离开。
- 联调真源位于 `apps/client/test/server/`；服务端侧通过 `./test/client/` 软链接访问。
- 运行方式：一个终端在 `apps/server` 执行 `npm run dev`；另一个终端执行：

  ```bash
  CLIENT_SERVER_ORIGIN=http://localhost:2568 \
    node --import tsx --test test/client/clientServer.integration.test.ts
  ```

# 邮件 · 分享

`MailShare` / `MailSharePanel`，750×1624，预览路由 `mail-share`，目录与标题「分享」。真源为 `AI标准化/邮件/邮件-分享_切图/reference/screen.png` 与切图参数；忽略的卡牌详情图层不实现。

- 弹窗 (21,377) 708×650，使用专用紫色窗底；标题独立文字，关闭 (654,394) 50×50，遮罩黑色 alpha=153。
- 列表底 (33,483) 683×518；单层 `VirtualList` (44,497) 661×490，选项行高 173px，白底 661×159。
- 默认选项「海域」与「[FTB]斧头帮」。海域图标 (87,516) 105×117；联盟图标 (85,692) 102×112。名称独立文字。
- 新增专用窗底、列表底、海域与联盟图标四张 PNG；白色卡片和关闭图按 SHA256 复用。
- 透明选项点击遮罩与视觉分离，按下不缩放。点击选项调用 `onSelect(destinationId)` 后调用 `onClose`；仅关闭或点击遮罩不发出选择事件。

`destinations` 可注入带稳定唯一 ID 的分享选项（名称、图标与尺寸）。默认 ID 为 `sea` / `alliance`。本页面只选择目的地，不接发送接口，也不显示虚假的分享成功提示。

战报详情「分享」打开本弹窗，与战斗日志、部队详情、士兵详情互斥；选择经父页面 `onAction` 发出 `share:sea` / `share:alliance`。选择或关闭后保留战报详情的滚动位置，支持邮件逐层返回。

预览登记覆盖目录、原稿首页、Web/Cocos 映射及 `createMailSharePreview`。验收：构建、同步、UniFlex 类型检查；首页打开、两个选项独立回调、关闭不选择、遮罩不穿透、详情/邮件返回链路。

# 邮件 · 部队详情

`MailTroopDetails` / `MailTroopDetailsPanel`，750×1624，预览路由 `mail-troop-details`，目录、入口和弹窗标题均为「部队详情」。原稿 `AI标准化/邮件/邮件-战报3_切图/reference/screen.png` 的标题为「部队增益」，本实现按用户指定的界面名命名，内容仍为原稿的双方增益对比。

- 窗体 (19,221) 714×1186，关闭 (680,223) 50×50，内容底 (40,303) 673×928。
- 表头 (40,303) 673×49，三列「我方 / 增益效果对比 / 敌方」。我方数值绿色，敌方红色，增益来源为浅紫字。
- 属性列表 (50,365) 656×851。单层变高 `VirtualList` 展平属性头（62px）和来源行（60px）；来源底图从 83px 的纯色切图适配为行高。没有嵌套虚拟列表。
- 示例三组：资源采集速度、部队负重、部队负重。两个同名组按原稿保留，以不同 ID 独立开合；初始前两组展开，第三组收起。所有示例值为我方 16.22%、敌方 0%，来源「船只科技」。
- 点击属性头开合并同步翻转箭头；透明点击遮罩与视觉分离，按下不缩放、位移或变暗。无来源的组不显示箭头并禁用开合。
- 新增 2 张 PNG：属性行底、展开内容底；窗底、关闭、表头、内容底和箭头按 SHA256 复用现有资源。原稿没有奖励区。

`groups` 可注入增益及来源数据（稳定且唯一的组 ID、组内来源 ID）；`onAction` 提供 `expand:<id>` / `collapse:<id>`；`onClose` 关闭。数据属于客户端展示，未接服务器属性计算。

战报详情的「部队详情」入口打开本面板。与战斗日志互斥显示，关闭后保留战报详情的滚动位置。重新打开按各组 `initiallyExpanded` 恢复，适用于邮件 → 战报详情 → 部队详情链路。

预览登记：`screens.json`、`catalog.ts`、`preview-screen.ts`、原稿 `PreviewHome`、`previewCatalog.ts` 及 `createMailTroopDetailsPreview`。

验收：`build:uniflex-ui` → `sync:client` → `typecheck:uniflex-ui`，原稿首页打开、三组开合、按住无缩放、关闭重开、详情/邮件往返。

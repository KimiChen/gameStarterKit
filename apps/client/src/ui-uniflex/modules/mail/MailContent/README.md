# 邮件 · 邮件内容

`MailContent` / `MailContentPanel`，750×1624，目录、路由和标题分别为「邮件内容」、`mail-content`、「邮件内容」。原稿文件夹虽名为 `邮件-战报4_切图`，实际是带附件奖励的联盟欢迎邮件，不按战报命名组件。

- 窗体 (19,221) 714×1186，关闭 (680,223) 50×50，复用战报详情窗底；无额外大内容底。
- 邮件主题 (60,312) 570×44；下划线 (57,356) 638×3；翻译底 (652,310) 38×38、图标 (657,315) 32×32，点击区域 50×50。
- 正文使用单层变高 `VirtualList`，位于 (60,370) 636×650；段落内只排带颜色的文字片段。原稿换行与段距通过 `MailContentParagraph` / `MailContentRun` 数据保留，正文 26px，五个重点前缀为红色。长正文可扩展段落列表，不覆盖固定奖励和底部按钮。
- 奖励底 (38,1050) 673×168，独立标题「奖励」；钻石含格底切图 (329,1108) 93×95，右下角数量独立文字，默认 99。
- 删除 (77,1279) 255×102，领取 (419,1279) 255×102。领取按钮切图与已登记黄色按钮字节不同，单独登记并使用九宫格；删除按钮复用。
- 新增奖励底、钻石格、翻译图标、翻译底与领取按钮五张 PNG，校验 SHA256；窗底、关闭与删除按字节复用。

可注入 `subject`、`paragraphs`、`rewardCount`、`claimed`、`onClose` 和 `onAction`。`claimed` 由外层持有，为 true 时显示「已领取」并禁用领取按钮。点击回调为 `translate`、`reward:gem`、`delete`、`claim`；本页不擅自更改服务器邮件、发奖励或生成翻译结果。

邮件列表「联盟」页签的「成功加入联盟」打开本页，关闭保留该页签和列表；战报条目继续打开战报详情，两种详情互斥。系统示例邮件仍保留原有回调，未套用联盟欢迎正文。

预览登记：目录、原稿首页、Web/Cocos 预览映射、`createMailContentPreview`。验收：构建、同步、UniFlex 类型检查；首页打开与关闭重开、四种操作回调、联盟邮件往返、战报入口回归。

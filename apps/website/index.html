GONO / GAMESTARTERKIT

把工程边界写进
游戏开发的第一天。

一个面向开发期的游戏基础框架：Cocos Creator、Colyseus 与 TypeScript 共享一条可验证的开发链。把第一天的工程纪律，留给每一次玩法迭代。

Cocos Creator 3.8.8Colyseus 0.17TypeScriptFairyGUIbitECS 0.4
01核心定位

开发期游戏基础框架

gono（gameStarterKit）把客户端、服务端和 shared 组织在同一份 monorepo 中，提供可替换的玩法接缝、本地调试和分层验证基础。

核心边界
  • 源码与生成镜像分离
  • 协议与公式单一真源
  • 引擎接缝可替换
  • 开发期规则可机检

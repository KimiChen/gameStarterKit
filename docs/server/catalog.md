## 建设标记怎样重新理解

| 标记 | 意味着什么 | 与最小核心的关系 |
|---|---|---|
| 基础 | 适用范围内的必要保障 | 可能是进程内保护，也可能是外部备份、健康采集或开发工具；不能据此全部内置 |
| 按需 | 选用业务后必须补齐的闭环 | 没有该业务就不加载；选用后不得只做正常路径 |
| 运营 | 提升持续维护效率 | 优先外部工具，可先提供受控命令，后补页面与自动化 |
| 扩展 | 规模或复杂度增长后补充 | 不预装完整集群平台，但提前保留兼容契约与责任边界 |

## 同一模块跨进程时如何处理

协议定义、接口适配、领域规则与外部管理界面可以归同一责任模块，但应分成不同装配入口。例如“监控模块”的日志输出属于薄适配器，检索与告警属于外部服务；“队列模块”的可靠登记属于提交链，持续消费属于 worker。上表按子职责拆解，避免整模块一刀切导致核心失去必要保障。

本次新增的是目标到运行边界的映射，没有把模块改成已实现状态；旧飞书表未在本轮自动修改。

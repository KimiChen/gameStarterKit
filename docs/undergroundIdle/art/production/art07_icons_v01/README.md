# ART-07 Icons 生产规范 v01

本目录计划生产 19 枚图标，覆盖当前策划清单的最小清晰集合：11 枚通用语义图标，以及从批准黄金 target/单体
同源提取的公会、设置、矿石、碎片、体力、矿井页签、工人页签、探险页签 8 枚首屏独立图标。被边框、文字或
邻近装饰污染的图标必须通过 mask 补绘或独立透明件生成，不得机械盲切。任何图标在实际导出和审计前都不得标记为最终采用。

每枚候选图标必须：

- 以批准 PNG 源和 `asset-manifest.json` 为生产真源，输出 256×256 RGBA PNG；
- 主体限制在 `(24,24)–(232,232)` 安全框内，外轮廓通常为 16 px，缩到 64 px 后约为 4 px；
- 左上高光、深色粗轮廓、暖黄铜/木材与冷钢铁/青绿点色沿用 `SPEC-03`；
- 不含可见文字、数字、伪文字、背景板或投影；四角保持透明；体力图标仅保留源符号的局部灯光，并裁切在安全框内；
- 不能只依赖颜色辨认：瓶颈使用收束轮廓与中央堵塞，禁用/锁使用锁体轮廓，倒计时使用表冠与时针，收取与领取分别使用“落入料斗”和“打开奖励箱”。

`resource` 与 `building` 规划为通用语义图标；`ore` / `shard` 与 `mine_tab` 规划为首屏契约专用入口，不能
替换通用图标。生产时应保留两类 ID，避免语义混用。

计划生成 `ug_art07_icon_contact_sheet_v01.png` 作为 2560×2048 审阅联系表：5×4 网格中，每枚候选图标
同时显示 256px 原图和 64px 缩小样本；标签必须位于 `90_REVIEW_ANNOTATION`，不属于可切取资产。首屏图标候选
应按 manifest 的 source rect/mask 确定性导出并回放到 composite。验收必须检查 19 枚数量闭合、四角透明、
安全边、无字、64px 形状可辨性和 target 风格一致性。候选生成后进入 `To audit`；检查与人工签字通过后才能
标记为 `Accepted`。候选尚未生成时保持 `To generate`。

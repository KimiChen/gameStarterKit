# ART-05 远征资产生产规范 v01

本目录规定如何把 FX-05 审阅目标拆成可独立装配的运行资产。候选尚待生成和审计；所有可见中文、数字、
解锁条件、时间和奖励范围必须由 FairyGUI 运行时节点提供，不得烘焙进本包。

## 内容与装配

- `locations/`：计划交付三张 640×360、sRGB、RGBA 地点插画。候选应由三张独立地点图产生；如只需增加
  Alpha 通道，必须证明主体像素未重绘，也不得从整页效果图裁切；
- route/：纵向路线以 128 像素节距平铺；横向连接段的九宫格有效区为
  [left=24, top=0, right=24, bottom=0]。
- nodes/：可用节点和锁定底座共用中心 pivot (64,64)；锁定语义还必须叠加独立锁形和运行时条件文字。
- states/：锁形 pivot (80,96)；菌光与遗迹雾均按地点卡中心 (320,180) 对齐。雾、锁、节点必须能
  分别关闭，不能合并进地点插画。

完整尺寸、pivot、来源组和伸缩策略必须在候选生成后登记到 `manifest.json`。路线只表达固定地点进度，
不允许拖拽或暗示实时移动。

## 验证

候选生成后在本目录执行：

    find . -name '*.svg' -print0 | xargs -0 xmllint --noout
    find . -name '*.png' -print0 | xargs -0 -n1 sips -g pixelWidth -g pixelHeight -g space -g hasAlpha

正式验收必须确认：

- 三张地点图均为 640×360 RGBA；
- 所有路线、节点、锁和雾 PNG 的四角 Alpha 为 0；
- SVG 不含 text 元素，PNG 不含文字、数字、水印或页面 UI；
- 64 像素节点缩小时仍可凭形状区分可用与锁定；
- FairyGUI 中路线使用平铺，连接段才使用登记的横向九宫格。

上述自动检查和人工复核完成前，本包状态保持 `To audit`，不得声称地点或拆件已经最终采用。

# ART-04 四角色生产规范 v01

本目录规定格伦、诺拉、伊芙和奥托四套角色资产的目标结构。计划从经人工选定并登记的
`main_v01/characters` rig 机械归一化头像、场景小人和拆件；本阶段不计划重新绘制身份或调用 ImageGen。
本文不表示这些源、导出物、哈希或 pivot 已经生成和审计。

## 计划交付结构

每个角色目录包含：

- `ug_worker_<id>_portrait_v01.svg/.png`：目标为 512×512 头像；由场景 rig 机械裁切，并保留至少 24px 输出边距；
- `ug_worker_<id>_scene_v01.svg/.png`：目标为 512×768 场景小人；SVG 应保留独立 image 节点和选定 rig 的遮挡顺序；
- `parts/`：计划包含头、身体、左右前臂、下身、标志工具和头灯的无损 PNG 副本，文件名与选定源一致。

包根目录另有：

- `manifest.json`：待登记来源、SHA-256、归一化变换、foot pivot、左右 wrist pivot、bbox 和裁切数据；
- `ug_art04_characters_contact_sheet_v01.svg/.png`：计划生成 2048×2048 审稿板，展示头像、场景小人、拆件、
  pivot 和实际导出后的 96/64 宽度轮廓测试。

## 归一化规则

- 场景画布统一为 512×768 RGBA；原 rig 按 `1.2×` 等比缩放，不做非等比拉伸。
- 脚底基线统一为 `y=720`，左右位置保留角色和标志道具的构图平衡；底部仍有 47px 透明空间。
- 候选场景 SVG 可在脚底基线裁掉最多 1px 的渲染器抗锯齿外溢；验收目标是 pivot 与可见底边均为 `y=720`；
- 头像应由归一化场景 rig 的登记方形 crop 产生，再整体缩进 24px；不得把它当作新的角色画稿；
- 对计划复制的拆件逐字节执行 SHA-256 比对。预期目标数量必须在 manifest 中登记，实际一致性待审计确认。

512×768 坐标。

| 诺拉 | `(255,720)` | `(250.2,427.2)` | `(193.8,446.4)` | 选择源 rig 后核对肩点；腕点候选取前臂袖口接缝并保持同一坐标系 |
| 伊芙 | `(240,720)` | `(84,542.4)` | `(408,540)` | 计划变换源 rig 的 `left-wrist` / `right-wrist` 工具登记点 |
| 奥托 | `(254,720)` | `(411.2,602.4)` | `(122,602.4)` | 计划变换源 rig 方箱/药包的 handle 登记点，作为持物腕点候选 |

若选定的格伦和诺拉源 rig 未登记 wrist，本包只能在候选 manifest 中补充与姿态一致的袖口锚点，不得反写或
伪造旧源证据。所有表中坐标都须在实际导出后复核。

## 使用边界

- 头像用于 64～96px 列表、卡片和选择槽；完整场景小人使用脚底 pivot 放置，不做纵向拉伸。
- 工具、头灯和前臂保持独立节点，可围绕 manifest 中的腕点或既有肩点做轻量程序动画。
- 灯光 bloom、呼吸和粒子不烘焙在角色 PNG 内，继续由独立 FX 节点承担。
- 本包计划只提供角色资产，不负责创建或修改 FairyGUI XML；完成后再由装配阶段引用经验收的导出物。

## 1. 文档目的与边界

本文把本目录已经确定的玩法、页面状态和视觉要求收敛为可走查的 UE（用户体验）流程与低保真线框，回答
“玩家当前看见什么、先读什么、点哪里、系统如何反馈”。它不是效果图、FairyGUI 设计源或已实现能力声明。

真相边界：

- 玩法、数值与状态规则以 01～03 文档为准；
- 页面生命周期、RPC、版本与结果未知处理以 [04](04-client-and-rpc.md) 为准；
- 权威数据、一致性与配置以 [05](05-data-and-server.md) 为准；
- 视觉语言、资产和动效以 [07](07-art-direction.md) 与 [08](08-main-screen-art-brief.md) 为准；
- 主界面 R1～R6、热区和安全区换算以 [09](09-fairygui-undergroundidle-main-assembly.md) 为准；
- 本文拥有首版页面流、信息层级、主次操作、弹窗顺序和异常反馈的 UE 口径。

本文中的方框只表示布局语义，不代表最终像素尺寸。除已由 09 固定的主界面外，其余页面必须在实现前建立
PageSpec，并由 FairyGUI Editor 保存最终坐标、Controller、Relation、热区和内部 ID。

## 2. UE 目标与页面清单

首版体验必须让玩家在一次短会话中完成：

```text
进入并取得快照
  → 看懂库存、产率与瓶颈
  → 收取仓库
  → 预览并升级建筑
  → 调整一次岗位
  → 选择地点与矿工
  → 确认机会成本后出发
  → 到期自动归队
  → 查看并领取固化奖励
```

| ID | 页面/层 | 首要问题 | 主操作 |
| --- | --- | --- | --- |
| UE-01 | 共用壳层 | 我在哪、现有资源多少？ | 三页签切换 |
| UE-02 | 矿场主页 | 现在能收多少、瓶颈在哪？ | 全部收取 |
| UE-03 | 建筑详情/升级弹窗 | 升级会改变什么？ | 升级 |
| UE-04 | 矿工页签 | 谁在做什么、擅长什么？ | 选择矿工/调岗 |
| UE-05 | 调岗面板 | 新岗位组合如何影响生产？ | 确认调岗 |
| UE-06 | 远征路线页 | 哪个地点可去、代价与回报是什么？ | 选择地点 |
| UE-07 | 编队确认弹窗 | 派谁、何时归队、损失多少？ | 开始远征 |
| UE-08 | 远征中/待领取页 | 还要多久，是否已经归队？ | 查看结果 |
| UE-09 | 远征结果弹窗 | 固化结果是什么，是否已到账？ | 领取奖励 |
| UE-10 | 离线收益弹窗 | 实际入仓多少、损失为何产生？ | 确认 |
| UE-11 | 加载/写入/结果未知层 | 操作是否完成，我现在能做什么？ | 查询或刷新 |

设置页、账号、社交公会、商店、装备、研究、每日委托和遗物收藏不在首版 UE 范围。

## 3. 全局导航与 750×1624 共用壳层

### 3.1 页面流

```text
玩法入口
  │
  ├─ 首次：activate
  └─ 已激活：getSnapshot
          │
          ├─ 有本次会话离线摘要 → UE-10 → UE-02
          └─ 无摘要 ─────────────────→ UE-02

UE-02 矿场 ─────┬──── UE-04 矿工 ─────┬──── UE-06/08 远征
  │             │                     │
  ├─ UE-03      └─ UE-05              ├─ UE-07
  │                                   └─ UE-09
  └──────────── 任一写操作可进入 UE-11 ────────────┘
```

页面一次只允许一个阻断层。离线摘要关闭后才出现引导高亮；升级、编队、结果等业务弹窗不在离线摘要之上
叠第二层弹窗。Toast、资源飞入和页签角标不是阻断层。

### 3.2 共用壳层

矿工与远征页继续保留标题、资源栏和底部三页签；中间内容区可以滚动。矿场页使用 09 已固定的六区结构，
中间矿井舞台不滚动。

```text
┌──────────────────────────────┐ y=0
│ R1 安全区 / 标题 / 设置       │ 0..108
├──────────────────────────────┤
│ R2 矿石 / 碎片 / 行动力       │ 108..207
├──────────────────────────────┤
│                              │
│ 当前页内容                    │ 207..1502
│ 矿场：R3 + R4 + R5（固定）    │
│ 矿工/远征：列表视口（可滚动） │
│                              │
├──────────────────────────────┤
│ R6  矿场     矿工     远征    │ 1502..1624
└──────────────────────────────┘ y=1624
```

共用规则：

1. R1、R2、R6 固定；列表只在内容区滚动，不能滑到资源栏或手势安全区下面；
2. 选中页签同时使用图标、文字和轮廓，不只换颜色；
3. 远征页签承载空槽、短倒计时和“待领取”三态，切页后仍保留状态摘要；
4. 顶部与底部按运行时 `safeTop/safeBottom` 换算，不把刘海、圆角或手势条画进背景；
5. 主要按钮与图标按钮的设计热区不小于 88×88；可见图标可以更小；
6. 页面滚动使用整卡吸附或自然停止，不做横向轮播，不把左右滑动作为唯一操作；
7. 长数字使用稳定宽度和统一缩写；弹窗内的关键成本、奖励与差额提供完整整数。

### 3.3 信息与操作层级

| 层级 | 内容 | 规则 |
| --- | --- | --- |
| L1 | 当前状态与主任务 | 首屏可见，不依赖滚动或展开 |
| L2 | 决策对比 | 必须出现在确认按钮之前 |
| L3 | 原因与精确值 | 就近展示，不藏在通用错误 Toast |
| L4 | 装饰与动效 | 不改变点击语义，不制造不存在的产量或完成状态 |

每个页面最多一个暖黄色主按钮。取消、关闭、返回使用次按钮或标题栏按钮；禁用主按钮保留原位置，并在按钮
上方或按钮内部给出具体原因。

## 4. UE-02 矿场主页

主界面沿用 [07 §4](07-art-direction.md#4-7501624-主界面结构) 与 09 的 R1～R6，不另建第二套坐标。

```text
┌──────────────────────────────┐
│ [公会]        矿场      [设置]│
├──────────────────────────────┤
│ 矿石 100   碎片 0   体力30/30│
├──────────────────────────────┤
│ 仓库 50 / 1,000    [全部收取]│
├──────────────────────────────┤
│ 格伦凿岩              升降机  │
│ [矿井热区]             诺拉   │
│                              │
│ 空矿车       伊芙      深层锁门│
│                              │
├──────────────────────────────┤
│ 开采12.8 运输19.8 有效12.8   │
│ 瓶颈：开采                    │
├──────────────────────────────┤
│ [矿场]       矿工       远征  │
└──────────────────────────────┘
```

交互顺序：

1. 进入后先更新权威快照，再播放本地增长；不能先用默认值闪现一帧；
2. 仓库有库存时“全部收取”是全页唯一主按钮；空仓时原位禁用并显示“暂无可收取矿石”；
3. 点击矿井、升降机、仓库或公会徽章打开 UE-03 对应变体；
4. 点击深层入口：未解锁时展示条件，已解锁时进入远征页并定位对应地点；
5. 点击矿工或远征页签进入 UE-04 或 UE-06/08；
6. 收取成功后整体应用新快照，库存归零、矿石余额更新，再播放一次短资源飞入反馈。

状态表达：

- 开采瓶颈：空矿车 + 镐头/警告形状 + “瓶颈：开采”；
- 运输瓶颈：入口矿石堆 + 升降机负荷形状 + “瓶颈：运输”；
- 仓库已满：停止入库表现 + 停止形状 + “已满”，不继续播放矿石飞入；
- 远征中：离岗角色消失但岗位牌保留，页签显示行走图标与短倒计时；
- 到达 `endAt`：角色自动归队，页签改为宝箱与“待领取”，不等待领取后才恢复岗位。

## 5. UE-03 建筑详情与升级

四类建筑共用同一个弹窗骨架；字段按建筑类型替换，避免四套交互规则。

```text
┌────────────── 背景变暗 ──────────────┐
│                                      │
│  ┌──────────────────────────────┐    │
│  │ 升级矿井                 [×] │    │
│  ├──────────────────────────────┤    │
│  │ [建筑阶段图]      等级 1 → 2 │    │
│  │                              │    │
│  │ 当前            升级后       │    │
│  │ 开采 12.8   →   20.8 /分钟   │    │
│  │ 凿岩岗位 1  →   2            │    │
│  │ 有效 12.8   →   19.8 /分钟   │    │
│  │ 升级后瓶颈：运输              │    │
│  │                              │    │
│  │ 消耗：100 矿石（持有 150）    │    │
│  │          [取消] [升级]        │    │
│  └──────────────────────────────┘    │
└──────────────────────────────────────┘
```

变体规则：

| 建筑 | 必看字段 | 条件区 |
| --- | --- | --- |
| 矿井 | 基础开采、岗位数、有效产率、新瓶颈 | 矿石成本 |
| 升降机 | 运输上限、岗位数、有效产率、新瓶颈 | 矿石成本 |
| 仓库 | 容量、预计满仓时间 | 矿石成本 |
| 公会大厅 | 新矿工、新地点、当前未满足条件 | 矿石、碎片、前置建筑 |

- 信息顺序固定为“变化 → 新瓶颈/解锁 → 成本/条件 → 操作”；
- 资源不足时按钮原位禁用，显示“还差 50 矿石”等精确差额；
- 前置条件不足时逐条列出，不把多个条件合成“条件不足”；
- 满级时隐藏价格和升级按钮，改为“已达当前最高等级”与关闭按钮；
- 点击升级后进入 UE-11 写入态；成功时关闭弹窗并应用完整新快照；
- `STATE_CONFLICT` 不保留旧价格继续确认，先刷新后重新打开最新预览。

## 6. UE-04/05 矿工与调岗

### 6.1 矿工页签

```text
┌──────────────────────────────┐
│              矿工      [设置]│
├──────────────────────────────┤
│ 矿石 150   碎片 0   体力30/30│
├──────────────────────────────┤
│ 当前岗位  凿岩1/1  运输1/1    │
│ ┌──────────┐ ┌──────────┐    │
│ │格伦 [凿岩]│ │诺拉 [运输]│    │
│ │开12 运5  │ │开5  运12 │    │
│ │勘4  生8  │ │勘7  生7  │    │
│ └──────────┘ └──────────┘    │
│ ┌──────────┐ ┌──────────┐    │
│ │伊芙 [空闲]│ │奥托 [锁定]│    │
│ │开4  运6  │ │大厅2级解锁│    │
│ │勘13 生8  │ │锁形+剪影  │    │
│ └──────────┘ └──────────┘    │
│                              │
│        [调整岗位]             │
├──────────────────────────────┤
│  矿场       [矿工]      远征  │
└──────────────────────────────┘
```

- 卡片同时展示姓名、四属性和权威状态，不出现等级、品质、装备或成长箭头；
- 工作中卡片显示具体槽位；空闲、远征中、已归队和锁定不能只靠颜色区分；
- 远征中卡片显示地点与归队时间，只读，不能加入本次调岗方案；
- 锁定卡显示明确解锁条件，不能点击后只弹通用错误；
- “调整岗位”进入 UE-05；若没有可调整槽位，原位禁用并解释原因。

### 6.2 调岗面板

调岗采用“先编辑草案、后一次确认”的方式，与 `assignWorkers` 原子替换岗位集合一致。拖拽可以作为增强，
但每个槽位必须同时支持点击选择，不能只依赖拖拽。

```text
┌──────────────────────────────┐
│ 调整岗位              [取消] │
├──────────────────────────────┤
│ 凿岩岗位                      │
│ [槽1 格伦 ▼] [槽2 未解锁]     │
│ 运输岗位                      │
│ [槽1 诺拉 ▼] [槽2 未解锁]     │
│ 空闲                          │
│ [伊芙]                        │
├──────────────────────────────┤
│ 调整后预览                    │
│ 开采 12.8 → 10.0             │
│ 运输 19.8 → 21.4             │
│ 有效 12.8 → 10.0             │
│ 新瓶颈：开采                  │
│ [还原]              [确认调岗]│
├──────────────────────────────┤
│  矿场       [矿工]      远征  │
└──────────────────────────────┘
```

草案规则：

1. 同一矿工不能出现在两个槽位；选择已占用矿工时提示“交换”或“移动”，不静默复制；
2. 未解锁槽位只展示条件，不接受放置；
3. 远征中矿工及其保留返回槽只读；到达 `endAt` 后刷新为已归队再允许编辑；
4. 每次草案变化立即本地计算预览，但请求只上传岗位集合，不上传产率或瓶颈；
5. 草案与权威岗位完全相同时禁用确认，并显示“岗位没有变化”；
6. 确认后锁定整页，成功时以完整快照覆盖草案；失败不伪造局部调岗成功。

- 路线纵向滚动，当前首个可用地点进入视口时完整可见；

- 已有在途或待领取远征时不显示第二个可开始的槽，改用 UE-08。

### 7.2 编队确认

```text
┌────────────── 背景变暗 ──────────────┐
│  ┌──────────────────────────────┐    │
│  │ 废弃坑道 · 编队确认      [×] │    │
│  ├──────────────────────────────┤    │
│  │ 选择矿工  1 / 1              │    │
│  │ [格伦] [诺拉] [伊芙✓] [奥托锁]│    │
│  │                              │    │
│  │ 队伍能力 11  最低5 / 推荐8    │    │
│  │ 行动力   30 → 29             │    │
│  │ 预计归队 1分钟后 / 14:35      │    │
│  │ 有效产率 12.8 → 12.8 /分钟   │    │
│  │ 机会成本 0 /分钟             │    │
│  │ 奖励范围：矿石…；碎片1        │    │
│  │                              │    │
│  │       [取消] [开始远征]       │    │
│  └──────────────────────────────┘    │
└──────────────────────────────────────┘
```

能力、行动力、归队时间、机会成本和奖励必须在主按钮之前。禁用态原因按优先级只突出一个主原因，同时保留
其他字段：

1. 上一远征待领取；
2. 远征槽占用；
3. 编队人数不符或矿工忙碌；
4. 能力低于最低值；
5. 地点未解锁；
6. 行动力不足。

“低于推荐但不低于最低”可以出发，使用非阻断提示说明可能得到较低等级；不能把推荐值误作硬门槛。确认后
进入 UE-11，不播放出发动画冒充服务端已接受。

```text
└──────────────────────────────┘
```

到达 `endAt` 后，同一位置切为：

```text
┌──────────────────────────┐
│ 废弃坑道                  │
│ [地点插画 + 归队剪影]      │
│ 已完成 · 矿工已自动归队    │
│ 远征槽：待领取             │
│              [查看结果]    │
└──────────────────────────┘
```

- 倒计时由服务端时间基线和本地单调时钟投影，不每秒请求；
- 首次跨过 `endAt` 只触发一次去重快照刷新；
- 进行中不显示取消、付费加速或提前领取；
- 待领取仍占用唯一远征槽，但不继续降低生产；页面和底栏同时表达这一差异；
- 点击“查看结果”打开 UE-09，关闭结果弹窗不会释放远征槽。

## 8. UE-09 远征结果

```text
┌────────────── 背景变暗 ──────────────┐
│  ┌──────────────────────────────┐    │
│  │          远征结果             │    │
│  │ [暗化地点插画 + 归队剪影]      │    │
│  │                              │    │
│  │        ┌────────┐            │    │
│  │        │ B 等级 │            │    │
│  │        └────────┘            │    │
│  │ 矿石 +18      遗迹碎片 +1     │    │
│  │ 事件：找到仍可使用的旧矿车。  │    │
│  │                              │    │
│  │          [领取奖励]           │    │
│  └──────────────────────────────┘    │
└──────────────────────────────────────┘
```

- C/B/A/S 使用字母与不同框形共同表达，不能只换颜色；
- 只展示服务端固化的等级、数量与事件，不在客户端重抽或补算；
- 首次古代遗迹通关时，徽记作为奖励清单中的独立一项；
- 点击领取后进入 UE-11；成功后资源入账、远征槽释放，按钮改为“奖励已领取”，再提供关闭；
- 领取结果未知时保留此弹窗语境，但用 UE-11 覆盖并阻止再次点击；
- 已领取回读只展示原领取凭证，不再播放第二次资源飞入。

## 9. UE-10 离线收益

弹窗在本次页面会话最多展示一次，内容来自快照投影摘要，不增加“确认已读”写请求。

```text
┌────────────── 背景变暗 ──────────────┐
│  ┌──────────────────────────────┐    │
│  │         欢迎回到矿场          │    │
│  ├──────────────────────────────┤    │
│  │ 计入收益时长：45分钟           │    │
│  │ 本次实际入仓：+576 矿石        │    │
│  │                              │    │
│  │ 容量损失：0                   │    │
│  │ 8小时上限：未触发             │    │
│  │                              │    │
│  │ 自动归队：无                  │    │
│  │ 待领取远征：无                │    │
│  │                              │    │
│  │             [确认]            │    │
│  └──────────────────────────────┘    │
└──────────────────────────────────────┘
```

容量与时间上限态保持同一结构：

- 先展示“实际入仓 1,000”，再分别解释“容量损失 5,144”和“已达到 8 小时收益上限”；
- 自动归队与待领取是两个事件卡，不能合成“远征完成”；
- 不把理论产量或损失量画成已到账资源；
- 底部只有一个确认按钮；关闭后回到 UE-02，再按权威库存决定是否可收取。

## 10. UE-11 加载、写入与结果未知

### 10.1 同槽位状态层

```text
┌──────────────────────────────┐
│       保留当前页面轮廓        │
│                              │
│        [状态图标/转轮]        │
│                              │
│      正在升级矿井…            │
│   请勿重复操作，结果将自动确认 │
│                              │
│       [条件出现的刷新按钮]     │
│                              │
└──────────────────────────────┘
```

| 状态 | 文案与操作 | 底层交互 |
| --- | --- | --- |
| LoadingSnapshot | “正在同步矿场…”；超时后给返回/重试读取 | 全部屏蔽 |
| Mutating | 使用具体动词，如“正在收取…” | 全部写操作屏蔽 |
| ResultUnknown | “正在确认本次操作结果…”；自动查询原 ID | 全部屏蔽 |
| Reconnecting | “连接中断，正在恢复…” | 只读展示，写操作屏蔽 |
| StateConflict | “状态已在其他位置更新”；刷新后关闭 | 全部屏蔽 |
| DataLost/Corrupt | “数据暂不可用”；返回，不提供重置 | 全部屏蔽 |

结果未知不是失败：

1. 保留原 `operationType + clientReqId + payload + expectedStateVersion`；
2. 先查询原操作或刷新快照，不能生成新请求 ID 猜测重做；
3. 快照暂时未变化也不能显示“操作失败”；
4. 得到 `applied` 后按版本守卫应用结果；低版本快照不能覆盖当前状态；
5. 超出收据窗口时停止自动重放，展示“结果已过期，请刷新状态”，不提供再次扣费式快捷按钮。

### 10.2 轻量反馈

- 成功：局部数值更新 + 一次 0.8～1.2 秒 Toast；关键奖励可以飞入资源栏一次；
- 可修正校验失败：弹窗内原因区就地显示，保留玩家选择；
- 服务端拒绝或冲突：不播放成功动画，不先扣本地资源；
- 限流：禁用相关操作并显示可重试时机，不高频倒计时请求；
- 页面关闭：停止旧 View 渲染；重新进入必须取新快照，不让迟到响应写回旧页面。

## 11. 新手引导与返回规则

### 11.1 首次体验引导

引导步骤尽量从权威状态推导，不保存一组能跳过经济动作的本机完成布尔值。第一步只负责讲解，可在本次
页面会话中关闭；若玩家尚未完成第一次收取，重进后允许再次展示。

| 步骤 | 高亮 | 完成判定 |
| --- | --- | --- |
| 1 | 仓库、三项产率和瓶颈 | 本次会话点击“继续”；尚未首次收取时可重现 |
| 2 | 全部收取 | 权威快照/操作结果体现初始库存已收取 |
| 3 | 一个可升级建筑 | 权威建筑等级提高 |
| 4 | 矿工页与调岗 | 权威岗位集合相对初始阵容发生合法变化 |
| 5 | 废弃坑道与伊芙 | 权威状态存在对应远征或其结果 |
| 6 | 待领取角标与结果 | 权威领取凭证表明奖励已领取 |
| 7 | 公会大厅 | 大厅达到 2 级 |

高亮只遮暗无关区域并给出一句短提示，不强制锁死所有其他页签。若目标已由另一设备完成，刷新后直接进入
下一步；不得要求玩家重复升级或重复派遣。

### 11.2 返回与关闭

1. 业务弹窗返回先关闭当前弹窗，不切换底层页签；
2. 调岗草案未提交时返回，先给“放弃本次调整？”；没有变化时直接返回；
3. 编队弹窗返回只丢弃本地选择，不改变行动力、岗位或远征槽；
4. 远征结果弹窗可在领取前关闭，结果与槽位仍保留；
5. Mutating/ResultUnknown 时返回不生成取消语义；允许离开玩法，但重进必须先恢复原操作结果；
6. 首版不提供远征取消，也不把系统返回键映射成取消远征。

## 12. UE 验收矩阵

| 场景 | 必须看见 | 禁止表现 |
| --- | --- | --- |
| 新手初始 | 50/1,000、开采瓶颈、三名角色、空远征槽 | 奥托、付费入口、假满仓 |
| 空仓 | 原位禁用收取 + 明确原因 | 可点击黄色收取按钮 |
| 仓库已满 | 已满文字/形状、停止入库表现 | 矿石继续飞入 |
| 建筑资源不足 | 完整差额与升级后预览 | 只变灰、不说原因 |
| 调岗 | 三项产率与新瓶颈预览 | 客户端预览当权威结果 |
| 地点锁定 | 内容价值与精确条件 | 可用态 CTA |
| 能力不足 | 当前/最低/推荐值与原因 | 模糊“队伍不符合要求” |
| 远征中 | 队伍、倒计时、归队时间、机会成本 | 取消、加速、提前领取 |
| 已到 endAt | 矿工已归队 + 槽位待领取 | 仍显示矿工离岗 |
| 领取成功 | 固化奖励、资源更新、槽释放 | 二次领取外观 |
| 离线 10 小时 | 实际入仓、容量损失、8 小时上限分行 | 把损失画成到账 |
| 超时/掉线 | 原操作正在确认 | 新 ID 重试或先显示失败 |
| 长数字/安全区 | 不跳动、不截断、主按钮可达 | 内容压到刘海/手势区 |

Creator 人工走查至少覆盖 `safeTop/safeBottom = 0/0` 与 `88/68`、资源 `9.99M`、仓库
`40,000/40,000`、大厅多前置条件、四名矿工、古代遗迹双人编队、远征 `00:01 → endAt`、正常/上限离线摘要，
以及收取、升级、调岗、派遣、领取五种写操作的 ResultUnknown 恢复。

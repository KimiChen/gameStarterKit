# 复刻 Sephiria 战斗系统：Cocos Creator 竖版手机版规划

> 依据：`docs/COMBAT.md`（伤害管线全公式）、`src/`（带注释 C# 参考，作规格书用）、`assets/Data/`（内容数据 Schema，可直接复用）。
> 原则：复刻架构，不复刻代码/资产（原作版权属 TEAM HORAY）。
> 前作验证：竖版俯视角动作肉鸽在手游上已被《元气骑士》《战魂铭人》充分验证。

## 〇、总体判断

**战斗内核（伤害管线/属性/状态/事件墙）与引擎和屏幕方向无关，100% 可平移**；
竖版真正改变的是三件事：**操作层（触屏）、镜头与关卡设计（窄视野）、弹幕密度与节奏**。
C# 参考源码不移植，当"带注释的规格书"读；数据 JSON 几乎直接当配置用。

## 一、技术映射表（Unity 概念 → Cocos Creator 3.x / TS）

| 原作（Unity/C#） | 你的实现（Cocos/TS） | 备注 |
|---|---|---|
| MonoBehaviour | `cc.Component`（TypeScript） | 生命周期一一对应 |
| ScriptableObject 实体 | **JSON 配置 + 数据类** | `assets/Data/*.json` 可直接当范本（FireData/Status/Const） |
| Physics2D | 自写轻量碰撞（圆形 vs 扇形/矩形）或 builtin 2D 物理 | 原作移动本来就是自研 TopdownRigidbody，自写反而更贴近参考 |
| DamageInstance 对象池 | 同名 TS 类 + 对象池 | 手机上池化是硬要求 |
| Mirror（服务端权威） | 先不做；后期 Colyseus/自建 WebSocket 房间 | 见 P8 |
| FMOD | Cocos 音频或 Wwise/自接 | |
| Tilemap | Tiled 导入 / cc.TiledLayer | 地牢房间用 Tiled 画 |
| Input System | 输入抽象层（虚拟摇杆/技能按钮 → 意图接口） | **学原作 PlayerInputController 的"意图层"设计** |

**四柱一表达式不变**：`DamageData`（池化载体）→ `applyDamage()` 20 步管线 → `StatDict`（字符串键属性字典）
→ 事件墙（`onCalculateDamage/onEvade/onCounter/onGuardSucceeded`）→ 状态表达式 `"ID/数值"` 中央工厂。
这五件套是纯逻辑层，一个 TS 文件一个类就能落地。

## 二、竖版手机的重设计（与 PC 版的差异点）

### 1. 镜头与视野
- 竖屏可视宽度约为横屏 60%：**同屏威胁数减半**（3-5 个活跃敌人），弹幕密度下调，
  弹速下调 20-30%——竖版弹幕是成熟品类（东方系），"下压式"弹幕天然适配
- Boss 房间用**纵向长屏**：Boss 固定上方 1/3，玩家下方 2/3 走位——原作 QQQBoss 的
  圆环/激光/坠落模式可以无损适配，横向扫射类要改成纵向

### 2. 操作层（竖版的命门）
- 左手：虚拟摇杆移动；右手：攻击（可设自动）/冲刺/格挡按钮
- **自动瞄准从第一天就做**（原作自带 `autoAimedTarget` 的设计直接抄：最近敌人 + 摇杆偏移修正）
- **完美格挡的触屏化**：按钮按下进入格挡，"按下后 150ms 内被击中"= 完美（原作是时间窗判定，
  触屏按钮天然适合）；冲刺 = 按钮或摇杆快速轻拂
- 自动拾取、自动开箱——减少手机上的碎片操作
- 触感：受击/格挡/完美格挡三档震动（手感的一半在震动）

### 3. 手机特有
- **随时可存档**：手机会随时被打断——参考原作"楼层切换存档"的粒度，
  但要加"切后台 30s 自动快照"
- 会话设计：单层 3-5 分钟，一局 15-25 分钟（原作单层偏长，手机上砍半）
- 性能预算：中端机 60fps → 同屏弹幕 ≤80、伤害数字池 ≤30、特效分级

## 三、分期施工

### P0 骨架（1 周）
Cocos 3.x 项目、竖屏画布 1080×1920、虚拟摇杆+冲刺/格挡按钮、Tiled 测试房、训练假人。
✅ 单拇指能跑能冲。

### P1 战斗最小闭环（1-2 周）
TS 版四柱落地：`DamageData` + `applyDamage` 精简链 + 近战判定 + **自动瞄准**。
✅ 能打死假人；摇杆走位时准星自动锁敌。

### P2 手感三件套（2-3 周）
冲刺无敌帧 / 格挡（扇形判定 + **MP 防御资源** + 触屏完美格挡 150ms 窗）/ 硬直击退 / 三档震动。
✅ 盲测："冲过弹幕、卡完美格挡"的爽感成立。

### P3 完整公式（1-2 周）
20 步管线全量 + 四条对数曲线（护甲 `ln(防/40+1)×0.445`；闪避 `100×ln(闪/6200+1)×0.8`；
处决=暴击溢出转掷 ×2；伤害下限 1）。
✅ 数值测试面板输入面板值，输出曲线与公式一致。

### P4 属性与状态（2 周）
`StatDict` + `StatusInstance` 家族 + `"ID/数值"` 工厂 + 四元素 + 溢出转换。
✅ 配置表里加一行 JSON 就能出新 Buff。

### P5 武器数据驱动（2-3 周）
`WeaponEntity`/`FireData` 用 JSON（直接参考 `assets/Data/NewWeaponFireData_*.json` 的字段设计）；
**relatedStatFormula（HIGHEST/AVERAGE）必须保留**——"武器跟随构筑"是复刻的灵魂之一。
3 个原型：近战挥砍 / 弹丸 / 蓄力。
✅ 新武器 = 一行 JSON + 0 行代码。

### P6 敌人 AI（2-3 周）
状态机 `Idle→Chase→Telegraph→Fire→Recover`，**attackPhase 公开可读**（前摇可读性=手机小屏上
玩家反应的前提）；3 原型：近战追击 / 纵向下压弹幕 / 冲锋。
✅ 每次出手有可读预警。

### P7 打磨（1-2 周）
池化伤害数字（分色分字号）、屏震（竖屏幅度调小）、顿帧、音效、结算面板。
✅ 闭眼能"听出"格挡与完美格挡。

### P8 联机（可选，3-4 周+）
Colyseus（房间制服务端权威，TS 同构）或自建 WebSocket；联机缩放照抄（Boss HP+90%/人）。
⚠️ 手机网络更不稳，"无重连"设计在手机上是差评放大器——要么做快照重连，要么明示。

### P9 手机工程化（贯穿）
包体（首包 <200MB，资源分包）、发热控制（帧率档位）、iOS 签名/安卓渠道、防 cheating（后期）。

## 四、内容量产策略

管线稳后按"每类 5-10 个起步"：武器 6 把、状态 30 个、敌人 10 种、Boss 2 个（一个弹幕型一个冲撞型）。
原作体量（546 开火数据/186 状态）是数年积累，**原型阶段用 1/20 的内容验证 100% 的管线**。

## 五、坑清单（Cocos/竖版特有 + 前次教训）

1. **别用 Cocos 物理做移动**：参考原作自研移动碰撞（圆形+分离），物理引擎管碰撞回调就够了——
   手感代码要自己握。
2. **触屏延迟**：输入→响应全链路 >80ms 手感即崩；渲染管线提前压（合图、减少节点层级）。
3. **对象池第一天就建**（手机 GC 卡顿是手感杀手）。
4. **序列化布局敏感**（Unity 事故的通用教训）：JSON 配置带版本号字段，改 Schema 必须写迁移。
5. **竖屏 UI 安全区**：刘海/手势条区域不放操作按钮。
6. **计时器单源**：冷却/前摇统一一个时钟服务，为将来联机留门。
